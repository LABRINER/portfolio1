# 📁 Структура портфолио

```
portfolio1/
├── index.html              # Главная страница
├── README.md               # Документация
├── STRUCTURE.md           # Этот файл
├── package.json           # Метаданные проекта
├── .gitignore             # Git игнор
│
├── styles/
│   ├── main.css           # Основные стили
│   └── responsive.css     # Адаптивные стили (опционально)
│
├── js/
│   ├── main.js            # Главный скрипт
│   └── utils.js           # Вспомогательные функции (опционально)
│
├── images/                # Папка для изображений
│   ├── project1.jpg       # Скриншот проекта 1
│   ├── project2.jpg       # Скриншот проекта 2
│   └── project3.jpg       # Скриншот проекта 3
│
└── assets/                # Другие ресурсы
    ├── resume.pdf         # Резюме (опционально)
    └── fonts/             # Шрифты (опционально)
```

## 📝 Описание файлов

### `index.html`
Главная HTML страница портфолио с полной структурой:
- Навигация
- Главный экран (Hero)
- Секция "О мне"
- Галерея проектов
- Секция навыков
- Форма контактов
- Футер

### `styles/main.css`
Основные стили включают:
- Переменные CSS (цвета, переходы)
- Стили навигации
- Hero-секция с градиентом
- Карточки проектов
- Адаптивный дизайн (media queries)
- Анимации

### `js/main.js`
Функционал:
- Мобильное меню (hamburger)
- Плавная прокрутка якорных ссылок
- Анимации при скролле
- Счётчик статистики
- Активные ссылки при скролле

### `README.md`
Основная документация проекта с:
- Описани��м
- Ссылками на проекты
- Контактной информацией
